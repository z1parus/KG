# Roadmap: Приложение заказа еды из локального ресторана

Этот каталог содержит исследовательские заметки и план реализации проекта приложения
для заказа еды из локального ресторана твоего города.

## Вводные (по результатам опроса)

| Параметр | Значение |
|---|---|
| Платформы | Веб + мобильные (iOS, Android) |
| Стек клиента | Flutter / Dart |
| Бэкенд | BaaS (рекомендация: Firebase, альтернатива — Supabase) |
| Фокус MVP | Классический заказ еды: меню, корзина, оформление, доставка/самовывоз |
| Команда | Небольшая (2–3 человека) |
| Оплата | На первом этапе — наличные/карта курьеру; онлайн-оплата в фазе 2 |

## Краткая сводка плана

- **Фаза 0 — Подготовка** (1 неделя): репозиторий, Firebase-проект, CI, дизайн-система.
- **Фаза 1 — Каталог** (2–3 недели): меню, категории, карточки блюд, поиск.
- **Фаза 2 — Заказ** (2–3 недели): корзина, адрес, выбор доставки/самовывоза, отправка заказа.
- **Фаза 3 — Ресторан** (2 недели): админ-панель для приёма и обработки заказов.
- **Фаза 4 — Пользователи** (2 недели): аккаунты, история заказов, статусы заказов, push-уведомления.
- **Фаза 5 — Онлайн-оплата** (по потребности): подключение эквайринга (ЮKassa/Stripe/Tinkoff).
- **Фаза 6 — Релиз** (1–2 недели): сторе, маркетинг, аналитика.

Ориентировочно: ~10–13 недель до MVP-релиза при стабильной работе 2–3 человек.
